# Optimización de Procesos Metalúrgicos mediante Modelos Predictivos
## Analisis-de-calidad-en-tubos

Análisis exploratorio y de procesos (EDA): Limpieza y análisis multivariado de parámetros operativos (temperaturas de temple/revenido, caudal, velocidad de vía, química del material) identificando causas críticas de desvíos de calidad.   

Modelado predictivo supervisado: Entrenamiento y evaluación de algoritmos (Decision Tree y Random Forest) para predecir si el tubo cumple con los estándares mecánicos antes del ensayo destructivo, alcanzando un 84% de exactitud (accuracy).   

Optimización alineada al negocio: Ajuste de hiperparámetros mediante una función de pérdida/costo personalizada orientada a minimizar falsos positivos/negativos, maximizando la rentabilidad y reduciendo cuellos de botella en inspección.
